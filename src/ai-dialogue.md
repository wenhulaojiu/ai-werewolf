# AI 真人感对话设计

本版本参考了 AIWolfGame、ai_werewolf、LLM-Werewolf 和本地 AI-Isnt-Here-参考项目中适合单人网页的思路，但没有复制其具体代码。

## 采用的机制

1. **角色记忆**：每个 AI 保存自己的最近发言和本局判断，不再每次从零开始。
2. **独立怀疑度**：每个 AI 都维护一份对其他座位的怀疑度，玩家的具体指控、含糊回答、前后逻辑和被点名反应会改变它。
3. **稳定人格与声音**：谨慎、直觉、分析、情绪、调停、强势、沉默、幽默等风格会影响句式和判断方式。
4. **回应具体对象**：AI 会优先回应上一位发言者，而不是连续生成互不相关的独白。
5. **角色约束**：AI 只能看到公开信息、自己的身份和自己的记忆；不会凭空知道其他角色身份。
6. **投票基于判断**：投票综合自己的怀疑度、他人被点名次数和少量随机性，避免每次随机投票。
7. **不输出思维链**：模型只输出适合群聊的最终发言，不展示内部推理过程。

## API Key 不可用时

本地模拟模式使用相同的怀疑度、人格、回应对象和记忆字段，因此即使没有 API Key，AI 也会保持基本的连续性和互动感。
